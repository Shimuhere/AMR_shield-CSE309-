API Connection Guide

Developer Mode

Overview

Connect your pharmacy's existing sales or billing software directly to the AMR-Shield network. This allows you to skip manual data entry while remaining compliant with national antibiotic tracking rules.

Authentication

Use your standard pharmacy login credentials to authenticate API requests via Basic Auth.

Authorization: Basic [Base64 Encoded Username:Password]

Sales Endpoint

POST /api/sales/

Send sale data in JSON format.

Example JSON Payload

{
    "antibiotic_name": "Azithromycin",
    "quantity": 3,
    "patient_age": 28,
    "patient_gender": "F",
    "doctor_name": "Dr. Sarah Khan",
    "prescription_reference": "TX-44021"
}

System Responses

201 Created

Sale successfully recorded and synced.

403 Forbidden

Authentication failed or role mismatch.
